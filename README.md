# -
电脑本地桌面陪伴宠物
桌面小猫咪 · Desktop Cat
一只住在 Windows 桌面上的陪伴小猫。可以撸、会翻滚、会睡觉、会翻肚皮，
还会时不时冒出一句「人类，你工作辛苦了」。

未能显示图片

特性
12 个真实姿态：坐、眯眼享受、蜷着睡觉、露肚皮、站立、抬爪击掌、洗脸、打哈欠、母鸡蹲、散步、兴奋、伸懒腰
可撸可玩：鼠标悬停抚摸 → 眯眼冒爱心；单击摸头 → 亲密度 +1；疯狂连点有连击奖励
会表达：不定期冒气泡说话，按早晨 / 午后 / 深夜切换台词
亲密度养成：9 个称号等级，进度自动存盘，关机不丢
不打扰：无边框透明窗口、不拦截鼠标，可以一直待在桌面角落；没人理 2 分半会自己打哈欠睡着
右键菜单：击掌、散步、洗脸、伸懒腰、打盹、喂小鱼干
运行
方式一：直接用打包好的程序（推荐）
到 Releases 下载 桌面小猫咪.exe，双击即可，不需要安装 Python。

首次启动要先解包，等 3~8 秒
如果 Windows 弹出「已保护你的电脑」，点「更多信息」→「仍要运行」即可
（这是未经数字签名的正常提示，不是病毒）
方式二：从源码运行
需要 Python 3.9 以上。直接双击 双击运行.bat：

如果你的 Python 已经装了 PySide6 → 立刻启动
如果没装 → 自动建一个独立运行环境并下载依赖（首次几分钟，之后秒开）
也可以手动：

BASH
复制
pip install -r requirements.txt
python main.py
文件说明
文件	说明
main.py	全部逻辑：行为状态机、动画、交互、亲密度
assets/	12 张猫的姿态贴图（透明底 PNG）
requirements.txt	依赖清单，只有一个 PySide6
双击运行.bat	一键建环境 + 启动
说明.txt	更详细的玩法与自定义说明
自己改
台词 → 搜 BY_HOUR / GENERAL / LOVE_LINES
亲密度等级 → 搜 LEVELS，改门槛和称号
动作触发频率 → 搜 _random_idle_action，里面是一张加权表
多久去睡觉 → 搜 idle_for > 150，150 的单位是秒（2 分半）
关于贴图
12 张姿态由 AI 图像生成（同一只橘白猫）+ AI 抠图，
统一缩放裁剪到 330×330 画布、猫脚底对齐底边。
程序运行时靠「切图」表现动作，只在翻滚 / 走路 / 跳跃时施加必要的位移与旋转。

隐私
程序不联网，也不读取任何个人文件。

只在自身目录写入两个文件：

cat_save.json — 亲密度、点击次数等养成数据
cat_pos.txt — 猫在屏幕上的位置
删掉整个文件夹即完全卸载，无残留。
